# 🎫 راهنمای سیستم لایسنس خان

سیستم لایسنس خان بر پایه **امضای دیجیتال Ed25519** طراحی شده — ضد دستکاری، ضد جعل، قابل ارتقا.

## 📊 حالت‌های لایسنس

| وضعیت | حداکثر کاربران | توضیح |
|--------|----------------|-------|
| 🆓 بدون لایسنس | **۲۰** | نسخه رایگان پیش‌فرض |
| ✅ لایسنس معتبر | **۵۰ / ۱۰۰ / ۵۰۰ / ∞** | طبق فایل لایسنس |
| ⚠️ لایسنس دستکاری‌شده | **۵** | جریمه — تقلب = ضرر |

## 🔧 ابزار تولید لایسنس

ابزار `gen-license` برای سازنده/فروشنده است — **در باینری اصلی نیست**.

### ساخت کلیدها (یک بار)

```bash
cd code
go run ./scripts/gen-license genkeys
```

خروجی:
- `private.key` — **فقط نزد شما بماند** (هرگز در ریپو/باینری)
- `public.key` — در باینری embed می‌شود

### امضای لایسنس

```bash
# لایسنس ۵۰ کاربری
go run ./scripts/gen-license sign private.key "شرکت نمونه" 50 2027-12-31 -out license-50.key

# لایسنس ۵۰۰ کاربری
go run ./scripts/gen-license sign private.key "شرکت بزرگ" 500 2028-06-30 -out license-500.key

# لایسنس نامحدود (∞)
go run ./scripts/gen-license sign private.key "شرکت سازمانی" 999999 2030-01-01 -out license-enterprise.key
```

### ساختار فایل لایسنس

```json
{
  "v": 1,                      // نسخه فرمت
  "t": "شرکت نمونه",            // نام شرکت
  "m_u": 100,                  // حداکثر کاربران
  "i": "2026-08-02T00:00:00Z", // تاریخ صدور
  "e": "2027-12-31T00:00:00Z", // انقضا
  "f": ["chat", "files", "reactions"],  // ویژگی‌ها
  "s": "..."                   // امضای Ed25519 (base64)
}
```

> هر تغییری در فایل (مثلاً `m_u` از ۱۰۰ به ۹۹۹) امضا را می‌شکند → **جریمه ۵ کاربر**

## 📥 نصب لایسنس در سرور

### از پنل مدیریت (راحت)

1. ورود با حساب ادمین
2. پنل مدیریت → تب **لایسنس**
3. دکمه «انتخاب فایل لایسنس»
4. فایل `license.key` را انتخاب کنید
5. وضعیت را ببینید:
   - ✅ **لایسنس معتبر** — سبز، با نام شرکت و انقضا
   - ⚠️ **نامعتبر** — قرمز، جریمه ۵ کاربر

### از API

```bash
# مشاهده وضعیت
curl -X GET http://localhost:1727/api/settings/license \
  -H "Authorization: Bearer $TOKEN"

# اعمال لایسنس
curl -X POST http://localhost:1727/api/settings/license \
  -H "Authorization: Bearer $TOKEN" \
  -F "license=@license.key"

# حذف لایسنس (بازگشت به ۲۰)
curl -X DELETE http://localhost:1727/api/settings/license \
  -H "Authorization: Bearer $TOKEN"
```

## 🧪 تست سیستم

```bash
# ۱. بدون لایسنس → ۲۰ کاربر
# ساخت کاربر ۲۱ام باید رد شود با پیام:
#   «ظرفیت مجاز (20 کاربر) تکمیل شده است»

# ۲. لایسنس معتبر → ۱۰۰ کاربر
# کاربر ۲۱ام ساخته می‌شود ✅

# ۳. دستکاری (تغییر ۱۰۰ به ۹۹۹)
sed 's/"m_u": 100/"m_u": 999/' license.key > tampered.key
# اعمال → رد + جریمه: ۵ کاربر ⚠️

# ۴. حذف → بازگشت به ۲۰ ✅
```

## 🔒 امنیت

| مکانیزم | توضیح |
|---------|-------|
| **Ed25519** | امضای نامتقارن — جعل بدون کلید خصوصی غیرممکن |
| **کلید خصوصی جدا** | فقط نزد سازنده — هرگز در باینری/ریپو |
| **کلید عمومی embed** | داخل باینری — تأیید آفلاین بدون اینترنت |
| **جریمه هوشمند** | دستکاری → ضرر (۵ کاربر) نه سود |
